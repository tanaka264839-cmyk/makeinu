# 負け犬の癒し

社会に「負け」と決められた人が、匿名で吐き出し、同じ境遇の人と話せて、心が休まる場所（SNS）です。  
公開中：https://makeinu.net/ （2026年11月から）

## どんなもの

- 匿名の板（6枚）、24時間で消える独り言、2人だけの小部屋、ゆるい名乗り
- AIの聞き役：人の返事が10分無い板の書き込みに、AIが一度だけ短く返す
- つらすぎる書き込みには、相談先（厚生労働省の案内で番号を確かめた窓口）をそっと出す
- 人を叩く言葉は止め、書きかけは消さずに残す
- 読んだ人が持ち主へ知らせる道、持ち主の見回り（管理画面）

## つくり

- Python の標準の道具だけで動く（外の部品を入れない）。記録は SQLite
- さくらのVPS（Ubuntu）に置き、入口は nginx（https）。AIの聞き役は さくらの AI Engine
- 毎日の控え、書いた人の記録（開示の求めに備えるだけで、画面には出さず半年で消す）、荒らしと連投への備え
- 開発には生成AI（Claude Code）を使い、何を作るか・設計・確認は人が判断しています

## 進め方（4本柱）

作る時・直す時は、毎回この4つをそろえています。

1. 言葉をそろえる：画面・関数・記録の名前を、同じ日本語の言葉で統一（板・独り言・小部屋・見回り・台帳 など）
2. 決めた理由を残す：[決定メモ.md](決定メモ.md)（なぜこう作ったか・捨てた案）
3. 工程の地図を持つ：[工程マップ.md](工程マップ.md)（機能と、関数・データの対応）
4. テストで動きを残す：[道具/テスト.py](道具/テスト.py)（161件）と [テスト結果.md](テスト結果.md)。普通でない使い方は [普通でない手順の一覧.md](普通でない手順の一覧.md) で当ててから出す

人に開く前にそろえた物（相談先の確かめ・利用の決まり・個人情報の扱い・通報・荒らしへの備え など）は [公開前に要るもの.md](公開前に要るもの.md) にあります。

## 手元で動かす

```
cd 道具
python -X utf8 場.py       # http://127.0.0.1:8765/
python -X utf8 テスト.py    # 161件（1件は Linux だけで動く）
```

ファイルごとの役目は [中身の地図.md](中身の地図.md) にあります。
